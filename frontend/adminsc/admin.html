SEO & Google

Atur bagaimana situs tampil di Google & saat link dibagikan

📝 Meta Tag Situs

Ideal 50–60 karakter.
Ideal 150–160 karakter.
Muncul saat link dibagikan di WhatsApp/Facebook. Pakai URL Cloudinary.

Perubahan langsung aktif di homepage (disuntik oleh Cloudflare). Untuk melihat di Google butuh beberapa hari.

🌐 Sitemap & Google Search Console

🔗 Buka Search Console 👁️ Lihat Sitemap
Cara daftar ke Google (sekali saja):
1. Buka Search Console → tambah properti suastawa-consulting.com
2. Menu Sitemaps → tempel sitemap.xml → Submit
3. Tempel URL homepage di kolom atas → Request Indexing

💡 Panduan Singkat SEO

• Title yang bagus: ada nama + lokasi + layanan (mis. "KJA & KKP Bali").
• Description mengundang klik, sebutkan keunggulan (izin resmi, sejak 2015).
• Update konten & galeri berkala — Google suka situs aktif.
• Minta klien puas menulis ulasan di Google Maps — sangat kuat untuk pencarian lokal.
• Jangan ganti Title/Description terlalu sering; beri jeda agar stabil di indeks.
